# v20260929g location.requireGps — 2026-09-29 HKT

## What was wrong with save
`DataStore.upsertLocation` in `data.full.js` **whitelist-mapped** location/question fields and **never wrote `requireGps`**.
Teacher UI collected per-question `requireGps` and put it in the payload, but the DataStore layer stripped it on every save — so 「不須到達」never persisted / reloaded.

## Fix
- Persist **`location.requireGps`** boolean (default true) in upsertLocation.
- Move teacher control from each question row → location modal 基本資料: `#lmRequireGps` 「到達要求：須到達 GPS / 不須到達」.
- Student Hub / location page use `locationRequiresGps(loc)` (migration: if missing, false only if ALL questions had requireGps===false).
- For requireGps=false: no 未到達 badge, no 可進入 GPS framing, no arrival rainbow; always enterable; questions unlocked without GPS.
